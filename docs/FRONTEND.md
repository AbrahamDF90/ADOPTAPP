# 🎨 Documentación Frontend - ADOPTAPP

## 1. Stack Frontend
*   **Motor:** Vite (Compilador ultrarrápido).
*   **Estilos:** Tailwind CSS (Utility-first).
*   **Lenguaje:** Blade (Motor de plantillas de Laravel).

## 2. Comandos de Vite
*   `npm run dev`: Levanta el servidor de desarrollo con Hot Module Replacement (HMR). Ideal para programar.
*   `npm run build`: Compila y minifica los assets para producción (genera la carpeta `public/build`).

## 3. Paleta de Colores y Diseño
*   **Fondo Navbar:** Negro (`bg-black`).
*   **Acentos Principales:** Verde Menta (`text-emerald-400` / `bg-emerald-600`).
*   **Acentos Secundarios:** Amarillo (`text-amber-400`), Rojo (`text-red-500`), Celeste (`text-sky-400`).
*   **Fondo General:** Gris claro (`bg-gray-50`).

## 4. Componentes Blade
*   Los layouts principales están en `resources/views/layouts/`.
*   Los componentes reutilizables (botones, inputs) están en `resources/views/components/`.
